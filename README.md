# 🐾 PawMatch

A modern pet adoption platform built with Vue + Firebase.

---

## 🚀 How to Run

Follow these steps to run the project locally:

1. Clone the repository:
   ```bash
   git clone https://github.com/zarafarrukh/pet-adoption-store.git
   cd pet-adoption-store
   ```
2. Ensure **Node.js** is installed  
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start development server:
    ```bash
   npm run dev
   ```
6. Open the local URL shown in your terminal (usually):
    ```
    http://localhost:5173
    ```

### ⚠️ Important
- A `.env` file is included with Firebase API keys  
- Ensure it stays in the **root directory**

## 🛠️ Tech Stack

### ⚡ Frontend (Vue Framework & Dynamic DOM)
- **Vue 3 + Vite**
  - Single File Components (`.vue`)
  - Composition API for state management
  - Scoped styling
- **Dynamic DOM Rendering**
  - Reactive pet catalog and "Paw-tique" store
  - Real-time shopping cart updates without page reloads

### 📊 Data Visualization (JavaScript, D3 & SVG/HTML)
- **D3.js**
  - Interactive donation jar math and scaling
- **SVG & HTML5**
  - Dynamic SVG path animations driven by user data
  - Semantic HTML architecture throughout components

### 🌐 AJAX, Web Services & Integration of New Technology
- **Firebase (Firestore)** - **✨ [New Tech]:**
  - Asynchronous AJAX calls to fetch live inventory of Paw-tique shop.
  - Cloud database integration to submit adoption applications.

### 🎨 Styling (CSS & CSS Frameworks)
- **Custom CSS3**
  - CSS variables for global theming
  - Responsive layouts (Flexbox/Grid)
  - Interactive `:active` state animations

### 🧰 Environment (Node.js)
- **Node.js + npm**
  - Local Vite development server
  - Package and dependency management
